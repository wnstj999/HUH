PRIVATE COMMUNITY TOOL

Organizing fair, reliable 5v5 in-house matches

LoL Inhouse Match Manager is a private project used to organize League of Legends matches for a community of more than 40 players. It helps organizers manage participants, prepare games, and keep match records in one place.

Open organizer dashboard

This project is not endorsed by Riot Games and does not reflect the views or opinions of Riot Games or anyone officially involved in producing or managing Riot Games properties.

PURPOSE

Built for a closed in-house community

The service supports community organizers who run private 5v5 matches. Players are managed by Riot ID, while current ranked information is retrieved through official Riot Games APIs to assist with participant administration.

FEATURES

Current and planned functionality

Current

Participant management

Register and identify community participants using their Riot ID.

Current

Rank lookup

Retrieve current ranked information from official Riot APIs and historical peak ranks from public OP.GG profile pages.

Planned

Tournament Code matches

After Tournament API approval, organizers will create games using Tournament Codes and automatically record completed match results.

PROJECT PRINCIPLES

Limited, transparent use of data

  • No monetization, advertising, paid features, or commercial use
  • No custom MMR or ELO rating system
  • Historical rank lookups are limited to public OP.GG profile pages and cached to reduce requests
  • No public matchmaking or open player-discovery service
  • Only data needed to operate the private community is processed

WORKFLOW

How a match is organized

  1. 01Community participants are registered by Riot ID.
  2. 02The organizer selects ten players for a private 5v5 match.
  3. 03A Tournament Code will be generated after API approval.
  4. 04Completed match results will be recorded automatically.
